## 二、基本面 v1 → v2 翻转详情

### v1 问题
"低PE + 老牌 + 高分红 = 好" → 总分-收益相关性 **-0.075**（越评分高越亏钱）

### 31,200样本归因分析

| 因子 | 60d相关 | v1方向 | 实际方向 | 修正 |
|------|---------|--------|---------|------|
| log_size(规模) | **-0.068** | 小盘好 | 小盘好 ✅ | 保留 |
| list_years(年限) | **-0.046** | 老牌好(≥10年=3) | **新股好(2-8年)** | 🔄 翻转 |
| dividend(分红) | **-0.034** | 高分红好(=3) | **不分红好(=3)** | 🔄 翻转 |
| PE_proxy(估值) | **-0.028** | 低PE好 | 低PE好 ✅ | 保留 |
| ROE | **+0.030** | 高ROE好 | 高ROE好 ✅ | 保留 |

### v2 设计：成长合理价模型

```
v1: 低PE + 老牌 + 高分红 + 大市值 → 价值陷阱
v2: 小盘 + 年轻 + 高ROE + 低PE  → 成长合理价
```

**7个子指标 (v2):**
1. `roe_quality` — 高ROE=竞争优势 (保留)
2. `valuation` — 低PE=安全边际 (保留)
3. `size_premium` — 小盘弹性 (保留，最强信号!)
4. `growth_stage` — 年轻公司2-8年=3分 (翻转!)
5. `reinvestment` — 不分红=成长=3分 (翻转!)
6. `financial_health` — 低负债率 (新增)
7. `growth_quality` — ROE+低负债 (重构)

### 验证结果

| 指标 | v1 | v2 | 变化 |
|------|-----|-----|------|
| 总分-60d相关 | -0.075 | +0.057 | **+0.132** |
| Q5-Q1 60d收益 | — | 单调递增 ✅ | — |
| 最强子指标 | — | size_premium +0.105 | — |

## 三、资金面 v1 → v2 翻转详情

### v1 子指标诊断 (2,137样本)

| 子指标 | 60d相关 | 判断 |
|--------|---------|------|
| flow_intensity | -0.022 | 🔴 最差，移除 |
| medium_contrarian | -0.039 | 🔴 反向，移除 |
| flow_divergence | -0.003 | 🔴 无效，移除 |
| flow_trend | -0.011 | 🔴 无效，重构 |
| flow_acceleration | +0.001 | ⚪ 中性 |
| super_large_ratio | -0.013 | ⚪ 短正长负 |
| **consecutive_inflow** | **+0.035** | 🟢 **唯一正向** |

7个中有5个负向/无效 → 正向信号被淹没。

### v2 设计：持续吸筹模型

```
v1: 主力流入+背离+超大单 → 5/7维度负向 = 总分负相关
v2: 持续流入+稳定+正向占比 → 3/7维度正向 = 总分正相关
```

**7个子指标 (v2):**
1. `persistent_inflow` — 连续5天+流入=3 (保留强化)
2. `flow_stability` — 低波动=稳定吸筹 (新增, +0.023)
3. `positive_ratio` — 80%+天数净流入 (新增, **最强+0.046**)
4. `flow_reversal` — 流出后反转 (新增, 但负向-0.031)
5. `smart_money` — 超大单+大单背离 (保留)
6. `flow_acceleration` — 流出→流入转折 (重构)
7. `relative_scale` — 相对市值规模 (替代绝对金额)

### 验证结果

|------|-----|-----|------|
| 总分-60d相关 | -0.013 | +0.013 | **+0.026** |
| 新增最强信号 | — | positive_ratio +0.046 | — |
| 数据限制 | — | 422只深市, 熊市期 | 需扩展 |

## 五、关键教训 (已确认)

> **同一规律在三个维度反复验证：**
> 
> 1. **朴素逻辑总是错的** — 追涨/主力买/低PE=好，三个v1全部失败
> 2. **极端 > 温和** — 极端超卖 > 温和回调，连续5天流入 > 单日流入
> 3. **小市值溢价普遍存在** — 技术面(小盘弹性)、基本面(size_premium最强+0.105)
> 4. **A股的本质是成长股市场** — 年轻+不分红+小盘 > 老牌+高分红+大盘

| 朴素逻辑 | 实际情况 | 维度 |
|---------|---------|------|
| 强势股=好 | 极端反转=好 | 技术 ✅ |
| 主力买=好 | 持续稳定买=好 | 资金 ✅ |
| 低PE=好 | 低PE+小盘+年轻=好 | 基本面 ✅ |
| 老牌+分红=好 | 年轻+不分红=好 | 基本面 🔄 |
