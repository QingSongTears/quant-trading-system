## 💡 经验沉淀 (未来参考)

1. **ABC + Protocol 分层**: BaseEngine / BaseDatafeed / BaseAlphaModel 三个 ABC 跨 4 个模块统一协议
2. **Lazy + 单例**: DataManager 5 类属性都 lazy, 启动 0 开销
3. **importlib lazy**: monkeypatch 友好 (AStockAlphaModel.load 用 importlib 而非 from import)
4. **fixture > mock**: `patched_xgb` fixture 比到处 monkeypatch 干净
5. **算法精度用 vnpy 对齐**: MACD/KDJ/boll 跟 TradingView/同花顺一致, 避免独自发明
6. **ddof 选 1 不是 0**: 样本标准差 (ddof=1) 跟主流库一致
7. **bindparam 优于 .format()**: SQL 安全, 未来改动无注入风险
