## 3. 关键依赖与风险点

### 3.1 外部依赖风险

| 依赖 | 风险等级 | 风险描述 | 缓解措施 | 负责人 |
|------|:--------:|----------|----------|--------|
| **AKShare** | 🔴 高 | 接口可能变更/限流/停止维护 | 备选 Baostock；数据下载后本地自足 | 后端 |
| **Backtesting.py** | 🟡 中 | 功能不足时需替换 | 预留引擎抽象层，可迁移 VectorBT | 后端 |
| **WeStock Data** | 🟢 低 | npm 包供应链风险 | 仅作为补充校验，非核心路径 | 后端 |
| **ECharts CDN** | 🟢 低 | CDN 不可用时图表无法渲染 | jsdelivr 国内有节点，可本地 fallback | 前端 |

### 3.2 技术瓶颈风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| SQLite 并发写入（多策略同时回测） | 写锁竞争 | 串行化回测任务，避免同时写入 |
| 全量下载耗时长（~75 分钟） | 首次体验差 | 提供增量模式；可后台下载 |
| BM25 索引内存占用（P3） | 回测数量多时内存增长 | 设置最大索引数（如 1000 条），LRU 淘汰 |

## 4. 页面清单与状态清单

### 4.1 页面清单（设计师评审用）

| 页面 | 路由 | 主要组件 | 状态 |
|------|------|----------|------|
| **首页仪表盘** | `/` | 数据卡片 ×4、快捷操作 ×3、最近回测列表、数据源声明 | 正常 / 空数据 / 加载中 |
| **数据管理** | `/data` | 覆盖统计、下载控制(全量/增量)、进度条、下载历史、数据源表 | 正常 / 下载中 / 下载失败 |
| **回测执行** | `/backtest` | 策略选择器、股票输入、日期范围、初始资金、运行按钮、结果区 | 配置中 / 运行中 / 完成 / 失败 |
| **回测详情** | `/backtest/<id>` | 指标卡片、净值曲线、回撤曲线、交易明细表、成本说明、风控分析(F8) | 正常 / 无交易 / 加载失败 |
| **策略管理** | `/strategies` | 策略列表、参数查看、策略来源说明 | 正常 / 无策略 |
| **多模型对比** | `/compare` | 净值叠加图、指标对比表、雷达图 | 正常 / 空(需选择) |
| **AI 分析 (P3)** | `/analysis` | AI 策略评估报告 | 正常 / 分析中 |

### 4.2 组件状态清单

每个页面核心组件的状态矩阵：

```
回测执行页 — 状态机:
  IDLE           → 显示配置表单
  VALIDATING     → 表单验证中
  RUNNING        → 加载动画 + "回测运行中..."
  COMPLETED      → 显示结果摘要卡片 + 链接到详情
  FAILED         → 红色错误提示 + 重试按钮

数据下载 — 状态机:
  IDLE           → 显示下载按钮
  DOWNLOADING    → 进度条 + 当前股票名称
  COMPLETED      → 完成统计 + 覆盖率
  PARTIAL_FAILED → 警告 + 失败清单
  ERROR          → 错误提示 + 重试选项
```

### 4.3 空状态设计

| 场景 | 空状态展示 |
|------|-----------|
| 数据库为空（首次使用） | "暂无数据，请先下载全市场历史数据" + 下载按钮 |
| 无回测记录 | "暂无回测记录，前往回测执行页开始" + 链接 |
| 回测无交易 | "该策略在回测区间内未产生任何交易信号" |
| 对比页无选择 | "请选择 2 个以上回测记录进行对比" |

## 5. 技术依赖与接口问题

### 5.1 后端依赖兼容性

| 依赖 | 版本 | 已知问题 | 建议 |
|------|------|----------|------|
| `akshare` | ≥1.14.0 | 部分接口需要网络稳定 | 添加重试 + 超时 |
| `backtesting` | ≥0.3.3 | 不支持 Pandas 2.2 部分特性 | 固定版本测试 |
| `fastapi` | ≥0.110.0 | - | 无问题 |
| `sqlalchemy` | ≥2.0 | 2.0 新 API 与 1.x 不兼容 | 统一使用 2.0 风格 |
| `pandas` | ≥2.2.0 | - | 无问题 |
| `rank-bm25` | ≥0.2.2 | 轻量纯 Python，无外部依赖 | F7 功能使用 |

### 5.2 前端依赖（全部 CDN 引入）

| 库 | CDN URL | 大小 | fallback |
|----|---------|------|----------|
| Bootstrap 5.3.3 | jsdelivr | ~60KB (gzip) | 可本地托管 |
| ECharts 5.5.1 | jsdelivr | ~1MB (gzip) | 可本地托管 |
| DataTables 1.13.8 | jsdelivr | ~120KB | 可降级为原生表格 |
| HTMX 1.9.12 | unpkg | ~14KB | 核心交互，需稳定 |
| Bootstrap Icons 1.11.3 | jsdelivr | ~200KB | 可降级为 emoji |

### 5.3 数据接口问题

| 问题 | 影响 | 建议 |
|------|------|------|
| AKShare 返回的字段名可能变更 | 下载器解析失败 | 添加字段存在性检查 + 兼容映射 |
| 复权方式不一致 | 回测结果偏差 | 统一使用前复权(qfq)；标注复权方式 |
| 退市股票处理 | 下载失败 | 记录 latest_date 为最后交易日 |
| 交易日历差异 | 部分日期无数据 | 使用实际交易日，不假设连续 |

## 10. 附录：新功能(F7/F8)技术可行性分析

### F7: BM25 记忆检索

```
复杂度: ⭐⭐ (低)
新增依赖: rank-bm25 (~50KB, MIT license)
实现位置: src/backtest/memory.py
数据流:   backtest_result → 特征编码 → BM25 索引 → 相似检索 API → 前端卡片
风险:     低。纯 Python 实现，不依赖外部服务。回测超过 1000 条后索引构建可能变慢。
建议:     v1.0 实现基础版本，v1.1 优化大规模索引。
```

### F8: 风控分析框架

```
复杂度: ⭐⭐⭐ (中)
新增依赖: numpy (已有), scipy (stats 模块，用于 VaR 计算)
实现位置: src/backtest/risk.py
数据流:   backtest_result → 日收益率序列 → VaR/CVaR/凯利/压力测试 → 展示
风险:     中。VaR 计算涉及统计分位数；压力测试的极端情景设计需要金融领域知识。
建议:     v1.0 实现 VaR + 凯利 + 最大回撤分析。压力测试作为 v1.1 功能。
```
