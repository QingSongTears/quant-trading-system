## 模型一：三因子均衡模型 🏛️

> **定位**: 长期持有基准，对标沪深300，追求年化超额5-8%

### 设计理念

A股被验证最有效的三个因子等权配置，不赌单一因子，依靠分散化平滑波动。

### 选股逻辑

```
每月第一个交易日调仓，三步筛选：
```

| 步骤 | 操作 | 参数 |
|:--:|------|------|
| **Step 1** | 剔除 ST、*ST、上市不足1年、股价<2元 | 全市场约剩4800只 |
| **Step 2** | 剔除日均成交额<3000万 | 流动性过滤，约剩3500只 |
| **Step 3-A** | 按总市值从小到大排序 → 取前100只 | 小市值因子 |
| **Step 3-B** | 按过去20日收益率从低到高排序 → 取前100只 | 反转因子 |
| **Step 3-C** | 按过去252日收益率标准差从低到高排序 → 取前100只 | 低波动因子 |
| **Step 4** | 三组各取交集权重33.3%，等权持有 | 共300只 |

### 参数配置

```yaml
model_1_three_factor:
  name: "三因子均衡模型"
  rebalance: "monthly"            # 月度调仓
  factors:
    small_cap:
      weight: 0.333
      rank_by: "total_market_cap"
      direction: "ascending"
      top_n: 100
    reversal:
      weight: 0.333
      rank_by: "return_20d"
      direction: "ascending"
      top_n: 100
    low_volatility:
      weight: 0.333
      rank_by: "volatility_252d"
      direction: "ascending"
      top_n: 100
  filters:
    - exclude_st: true
    - min_price: 2.0
    - min_list_days: 250
    - min_daily_turnover: 30000000  # 3000万

    type: "equal_weight"
    max_single_position: 0.02       # 单只上限2%
```

## 模型二：盾+矛全天候模型 ⚔️

> **定位**: 攻守兼备，熊市不崩、牛市跟上

### 设计理念

将策略分为防守组（红利+低波+质量）和进攻组（小市值+反转），牛市进攻组发力，熊市防守组撑底。再叠加一个「市场温度计」来动态调节两组权重。

### 选股逻辑

```
每月初评估市场状态 → 调节盾矛配比 → 执行选股
```

**市场温度计**（决定盾/矛比例）：

| 信号 | 判断标准 | 盾:矛 |
|------|----------|:----:|
| 🔥 进攻 | 沪深300 > MA60 且 MA20 > MA60 | 30:70 |
| 🌤️ 中性 | 沪深300 在 MA60 ±3% 区间 | 50:50 |
| 🧊 防御 | 沪深300 < MA60 且 MA20 < MA60 | 70:30 |

**防守组（盾）选股**：

| 因子 | 权重 | 筛选规则 |
|------|:--:|------|
| 红利 | 50% | 股息率≥4% + 连续分红≥5年，取前30只 |
| 低波 | 30% | 252日波动率最低20%，取前50只 |
| 质量 | 20% | ROE≥15% + 负债率<50%，取前20只 |

**进攻组（矛）选股**：

| 因子 | 权重 | 筛选规则 |
|------|:--:|------|
| 小市值 | 55% | 市值最小10%，剔除ST/低成交，取前80只 |
| 反转 | 45% | 20日跌幅最大15%，取前60只 |

### 参数配置

```yaml
model_2_shield_spear:

  rebalance: "monthly"
  market_thermometer:
    bull_signal: "close > ma60 AND ma20 > ma60"
    bear_signal: "close < ma60 AND ma20 < ma60"
    bull_ratio: "30:70"     # 盾:矛
    neutral_ratio: "50:50"
    bear_ratio: "70:30"
  shield_group:
    dividend: { weight: 0.50, min_yield: 0.04, min_years: 5, top_n: 30 }

    quality:  { weight: 0.20, min_roe: 0.15, max_debt: 0.50, top_n: 20 }
  spear_group:
    small_cap: { weight: 0.55, percentile: 10, top_n: 80 }

```

## 模型三：事件驱动增强模型 📡

> **定位**: 在小市值基底上叠加事件信号，追求超额Alpha

### 设计理念

小市值因子提供基础收益（Beta），事件信号提供增强收益（Alpha）。只在事件触发时才调整个股权重。

### 运作流程

```
每周五收盘后扫描事件：
  ├── 业绩超预期事件 → 加仓至3%（正常1%）
  ├── 北向连续加仓   → 加仓至2%
  ├── 业绩暴雷       → 踢出组合
  ├── 大股东减持     → 减仓至0.5%
  └── 无事件         → 维持等权
```

### 事件信号定义

**事件1：业绩超预期 📈 — 最重仓位信号**

```python
# 触发条件（全部满足）
条件1: 净利润同比增速 > 50%
条件2: 营收增速 > 20%
条件3: 经营现金流 / 净利润 > 0.9
条件4: 非ST、非首次盈利（排除扭亏噪音）
→ 动作: 个股权重从等权提升到 3×，持有40个交易日
```

**事件2：北向资金连续加仓 🏦**

```python
# 触发条件
条件1: 北向连续3日净买入
条件2: 北向持仓占比 > 2%
条件3: 近3日北向增持 > 0.3%
→ 动作: 个股权重从等权提升到 2×，持有20个交易日
```

**事件3：业绩暴雷 🚨 — 风控信号**

```python
# 触发条件（任一满足）
条件1: 净利润同比下降 > 50%
条件2: 商誉减值 > 净资产30%
条件3: 被ST/*ST/立案调查
→ 动作: 立即踢出组合，不计成本
```

**事件4：大股东减持 ⚠️**

```python
# 触发条件
条件1: 5%以上股东公告减持
条件2: 预计减持 > 总股本2%
→ 动作: 个股权重降至0.5×，持有至减持期结束
```

### 参数配置

```yaml
model_3_event_driven:
  name: "事件驱动增强模型"
  base_strategy: "small_cap"        # 小市值基底
  base_rebalance: "monthly"
  event_scan: "weekly"              # 每周扫描事件
  events:
    earnings_surprise:
      weight_multiplier: 3.0
      hold_days: 40
      conditions:
        - profit_growth_yoy > 0.50
        - revenue_growth_yoy > 0.20
        - operating_cf / net_profit > 0.90
    northbound_accumulate:
      weight_multiplier: 2.0
      hold_days: 20
      conditions:
        - northbound_consecutive_buy >= 3
        - northbound_holding_pct > 0.02
        - northbound_3d_change > 0.003
    earnings_crash:
      action: "remove"
      conditions_any:
        - profit_growth_yoy < -0.50
        - goodwill_impairment_ratio > 0.30
        - is_st == true
    major_selloff:
      weight_multiplier: 0.5
      conditions:
        - insider_sell_pct > 0.02
```

## 模型四：技术指标复合模型 📊

> **定位**: 整合现有5个策略，用投票机制产生信号

### 设计理念

不发明新策略，而是把已有的双均线/MACD/RSI/布林带/海龟五个策略变成"投票委员会"：5个策略各自对每只股票投票（买入=+1，卖出=-1，中性=0），总分≥2才买入。

### 投票规则

```
每只股票每天：
  双均线: 快线>慢线 → +1，反之 → -1
  MACD:   金叉状态 → +1，死叉 → -1
  RSI:    <30 → +1，>70 → -1，30-70 → 0
  布林带: 价格<下轨 → +1，>上轨 → -1，轨内 → 0
  海龟:   突破买入 → +1，跌破止损 → -1，持仓 → 0

总分 ≥ +2 → 买入
总分 ≤ -2 → 卖出
其他     → 持有
```

### 参数配置

```yaml
model_4_technical_voting:
  name: "技术指标投票模型"
  signal_frequency: "daily"
  stock_pool: "csi300"              # 沪深300成分股
  voting:
    ma_cross:
      fast: 5
      slow: 20
      vote: { golden_cross: +1, death_cross: -1 }
    macd:
      fast: 12
      slow: 26
      signal: 9
      vote: { golden: +1, death: -1 }
    rsi:
      period: 14
      vote: { oversold_30: +1, overbought_70: -1 }
    bollinger:
      period: 20
      std: 2.0
      vote: { below_lower: +1, above_upper: -1 }
    turtle:
      entry_period: 20
      exit_period: 10
      atr_period: 20
      vote: { breakout_long: +1, stop_loss: -1 }
  entry_threshold: +2               # 总分≥2买入
  exit_threshold: -2                # 总分≤-2卖出
  max_positions: 10                 # 最多持仓10只
  position_sizing: "equal_weight"
  risk:
    stop_loss: -0.08                # 单只止损-8%
    portfolio_stop: -0.15           # 组合止损-15%
```

### 回测验证

| 验证项 | 方法 | 预期 |
|--------|------|------|
| vs 单策略 | 对比5个单策略收益 | 投票模型夏普 > 任一单策略 |
| 交易频率 | 统计日均交易次数 | < 3次/天（避免过度交易） |
| 最大回撤 | 2015-2025 | < 25% |
| 胜率 | 盈利交易/总交易 | > 45% |
