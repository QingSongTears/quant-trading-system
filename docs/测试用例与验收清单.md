## 1. 测试策略

| 维度 | 策略 |
|------|------|
| **测试层级** | 单元测试 (pytest) → 集成测试 → E2E 测试 → 手动验收 |
| **覆盖目标** | 核心路径 100%，边界 80%，异常 60% |
| **数据真实性** | 每条测试用例必须标注数据来源是否经过验证 |
| **AI 标注检查** | 每个 Web 页面检查 AI 内容是否有「AI生成」标注 |
| **环境** | Python 3.10+ / SQLite / Chromium (Playwright) |

## 3. 边界场景测试

| # | 场景 | 预期行为 | 优先级 |
|---|------|----------|:------:|
| BE-01 | 初始资金 = 100 元（不足以买 1 手） | 提示 "初始资金不足以买入最小交易单位（100股）" | P1 |

| BE-05 | 策略从未产生交易（回测区间无信号） | 回测完成，报告中 total_trades=0，页面显示 "未产生交易" | P1 |
| BE-06 | 对比页选择 1 个回测 | 显示提示 "请选择 2 个以上回测记录" | P2 |
| BE-07 | 对比页选择 10+ 个回测 | 净值叠加图支持 10+ 条线，颜色循环 | P2 |
| BE-08 | 数据库 extremely 大（全市场 375 万行） | 查询 < 500ms，Web 页面 < 2s | P1 |
| BE-09 | 并发：同时 2 个 Web 请求触发回测 | SQLite 写锁排队，不崩溃 | P2 |
| BE-10 | 退市股票（如 000033 已退市） | 下载 latest_date 为退市日，增量更新正确跳过 | P1 |
| BE-11 | 北交所股票（bj430047） | 正常下载，market 字段为 BJ | P1 |
| BE-12 | 策略参数为浮点数边界（如 period=0.1） | 加载时报错参数不合法 | P2 |

## 4. 异常场景测试

| # | 场景 | 预期行为 | 恢复方式 | 优先级 |
|---|------|----------|----------|:------:|
| EX-01 | 下载过程中网络断开 | 记录当前进度，已下载的股票数据已持久化 | 重启下载（断点续传） | P1 |
| EX-02 | AKShare 接口返回格式变化 | 捕获异常，记录日志，跳过该股票 | 检查日志，更新字段映射 | P1 |
| EX-03 | 数据库文件损坏 | 提示用户 "数据库文件可能已损坏" | 删除 .db 文件重新下载 | P1 |
| EX-04 | 磁盘空间不足（< 1GB） | 下载前检查空间，不足则阻止下载并提示 | 清理磁盘后重试 | P1 |
| EX-05 | SQLite 写锁冲突 | 回测任务排队执行，Web 端显示 "等待中" | 自动重试 | P2 |
| EX-06 | ECharts CDN 加载失败 | 图表区域显示 "图表加载失败，请检查网络" | 刷新页面 | P1 |
| EX-07 | 策略代码有语法错误 | 加载时抛出异常，Web 策略页显示具体错误行 | 修复代码后重启 | P1 |
| EX-08 | 回测中策略产生除零错误 | 不中断回测，该次结果标注异常 | 查看日志定位 | P2 |
| EX-09 | FastAPI 端口 5050 被占用 | 自动尝试 5051→5052 | - | P2 |
| EX-10 | WeStock Data CLI 未安装 (Node.js < 18) | T4 功能降级，Westock 校验模块返回 "环境不支持" | 安装 Node.js ≥ 18 | P2 |
