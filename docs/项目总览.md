# A股量化交易模型系统 — 项目总览

> **最后更新**: 2026-06-16 | **当前阶段**: v1.0 已上线 → v2.0 规划中  
> **仓库**: [QingSongTears/quant-trading-system](https://github.com/QingSongTears/quant-trading-system)

---

## 一、项目定位

一个面向 A 股的**本地量化交易研究与回测系统**。核心能力：

```
数据下载 → 策略编写 → 回测验证 → Web 可视化 → 模型对比
```

目标用户：个人量化研究者，要求数据可控、策略灵活、可视化直观。

---

## 二、技术栈

| 层 | 选型 |
|------|------|
| 语言 | Python 3.10+ |
| Web 框架 | FastAPI + Jinja2 |
| 前端 | Bootstrap 5 + ECharts |
| 数据库 | SQLite (SQLAlchemy ORM) |
| 数据源 | AKShare（A股行情+财务+龙虎榜） |
| 回测引擎 | Backtesting.py |
| 部署 | 单机本地运行 (`python run.py --port 8000`) |

## 七、快速上手

### 克隆并运行

```bash
git clone https://github.com/QingSongTears/quant-trading-system.git
cd quant-trading-system
pip install -r requirements.txt

# 初始化数据库
python run.py --init

# 下载数据（首次全量，之后可 --download-incr 增量）
python run.py --download

# 启动 Web 服务
python run.py --port 8000
# 浏览器打开 http://localhost:8000
```

### 项目结构

```
quant-trading-system/
├── run.py                  # 入口（--init/--download/--port）
├── config/
│   ├── config.yaml         # 系统配置
│   └── strategies.yaml     # 策略配置
├── src/
│   ├── data/               # 数据下载与存储
│   ├── backtest/           # 回测引擎 + 策略基类
│   ├── strategies/         # 预设策略 + stock_screener
│   ├── models/             # v2.0 模型（bull_wave_catcher 等）
│   ├── scoring/            # v2.0 七维评分器
│   └── web/                # FastAPI + 路由 + 模板
│       ├── app.py
│       ├── routes/
│       └── templates/
├── data/                   # SQLite 数据库 + CSV 输出
├── docs/                   # 所有文档
└── scripts/                # 工具脚本（样本池构建等）
```
