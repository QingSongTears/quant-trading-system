# 七维共振牛股波段模型设计方案

> **版本**: v1.1 | **日期**: 2026-06-16 | **作者**: 项目 Leader  
> **核心思路**: 研究A股历史翻倍牛股的共性特征，提取可量化的多维度指标  
> **目标**: 在牛股启动期识别并捕捉，吃主升浪波段

---

## 一、研究方法

### 1.1 样本时间范围

```
2024-01-01 ~ 至今（动态更新）
```

覆盖2024年结构牛（AI算力、低空经济）、2025年全面牛（具身智能、AI硬件）两轮不同市场风格，确保模型不是只学会一种行情。

### 1.2 标准牛股定义（三阶段漏斗）

> **决策记录**: 牛股定义采用「纯翻倍 + 市值门槛 + 剔除游资短炒」方案，目标产出 **200+只** 标准牛股样本。

```
全A股（剔除ST + 上市不满250日次新股）
    │
    ▼ 阶段一：市值门槛 ──────────────────────
    启动市值 ≥ 30亿（剔除微盘垃圾股，排除纯游资标的）
    启动市值 ≤ 500亿（超大盘翻倍概率极低，排除）
    │
    ▼ 阶段二：翻倍定义 ──────────────────────
    定义：60个交易日内最大涨幅 ≥ 100%
    附加：翻倍启动前60日处于横盘或下跌（剔除"已在高位再翻倍"的加速赶顶股）
    │
    ▼ 阶段三：剔除游资短炒（满足任一即剔除）───
┌─────────────────────────────────────────────┐
│ ❶ 翻倍后30日内从最高点回撤 > 35%              │
│    真正的牛股不会A杀，机构主导品种回调可控      │
│                                              │
│ ❷ 翻倍期间日均换手率 > 20%                    │
│    过度投机信号，非机构主导                    │
│                                              │
│ ❸ 翻倍期间一字涨停 ≥ 7个                     │
│    纯情绪驱动，没有实际买入机会                │
│                                              │
│ ❹ 翻倍启动时 净利润 < 0 且 营收 < 1亿         │
│    垃圾股基本面，无持续上涨逻辑                │
│                                              │
│ ❺ 翻倍期间 龙虎榜游资净买入 > 机构净买入 ×3   │
│    纯游资接力推动，非机构+游资共识              │
└─────────────────────────────────────────────┘
    │
    ▼
  ✅ 标准牛股样本池（目标 ≥ 200只）
```

### 1.3 预估漏斗效应

| 阶段 | 过滤条件 | 2024估 | 2025估 | 合计 |
|------|------|:--:|:--:|:--:|
| 原始翻倍股 | 60日涨幅≥100% | 94 | 540 | 634 |
| → 市值过滤 | 30-500亿 | ~80 | ~350 | ~430 |
| → 翻倍质量 | 启动前非高位 | ~65 | ~250 | ~315 |
| → 剔除游资短炒 | 5条任一命中 | ~45 | ~180 | **~225** |

> **数据源**: 全量历史日线数据存放于 tdrive 项目资料库（`quant.db` `daily_price` 表），含 OHLCV 完整字段。上述为预估值，实际数据跑通后精确化。

### 1.4 牛股共性提取（8大规律 → 7个可量化维度）

```
历史牛股8大规律              映射到7个可量化维度
─────────────────────       ─────────────────────
① 启动市值20-80亿    ──→   基本面（规模+估值）
② 踩中时代最强主线   ──→   消息面 + 板块地位
③ 业绩预期差         ──→   基本面（增长指标）
④ 底部横盘倍量突破   ──→   技术面（形态+量价）
⑤ 股东结构干净       ──→   机构参与度
⑥ 题材纯粹单一       ──→   消息面
⑦ 板块梯队效应       ──→   板块地位
⑧ 回调温和不破趋势   ──→   技术面（趋势强度）
                      
新增A股特色：
  龙虎榜游资接力     ──→   资金面
  散户情绪极端       ──→   情绪面
  大盘环境配合       ──→   大盘行情
```

### 1.5 关键参数（可调参）

| 参数 | 默认值 | 说明 | 调参方向 |
|------|:--:|------|------|
| 启动市值下限 | 30亿 | 排除微盘垃圾股 | 下调 → 更多小盘妖股；上调 → 更偏机构票 |
| 翻倍窗口 | 60交易日 | 约3个月 | 缩短 → 更快爆发型；延长 → 慢牛型 |
| 游资回撤阈值 | 35% | A杀判断线 | 放宽 → 更多保留；收紧 → 更严 |
| 游资换手率阈值 | 20% | 投机度警戒线 | — |
| 一字板阈值 | 7个 | 无买入机会线 | — |

## 二、七维度量化指标体系

### 维度一：技术面（权重 20%）

> 识别「底部横盘 + 倍量突破 + 均线多头」形态

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **T1 底部横盘** | `base_consolidation` | 过去60日最高/最低-1 < 20% | < 20% 且天数>40 | 3 |
| **T2 量比突破** | `volume_ratio` | 当日成交量 / 5日均量 | > 2.0 | 4 |
| **T3 均线多头** | `ma_alignment` | MA5>MA10>MA20>MA60 | 4条全满足 | 3 |
| **T4 筹码集中** | `concentration` | 获利比例 > 70% | > 70% | 2 |
| **T5 缩量回调** | `pullback_volume` | 近3日缩量且未破MA10 | 回调幅度 < 8% | 3 |
| **T6 换手率** | `turnover_rate` | 日换手率 | 3%-15% | 3 |
| **T7 RPS强度** | `rps_rank` | 近20日涨幅排名 | > 90分位 | 2 |

> **技术面满分 = 20分，触发信号需 ≥ 12分**

---

### 维度二：资金面（权重 20%）

> 识别「主力资金入场 + 龙虎榜信号」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **F1 主力净流入** | `main_force_inflow` | 连续3日主力净流入 | 均>5000万 | 5 |
| **F2 大单占比** | `big_order_ratio` | 大单买入/总成交 | > 30% | 3 |
| **F3 龙虎榜净买** | `dragon_net_buy` | 买方前五 - 卖方前五 | > 0 且买方/卖方>1.5 | 4 |
| **F4 龙虎榜席位** | `dragon_seat_quality` | 机构+游资+北向共同买入 | 2类以上同时买入 | 3 |
| **F5 封板质量** | `limit_up_quality` | 涨停封单量/流通盘 | > 1% 且未炸板 | 3 |
| **F6 北向增持** | `northbound_increase` | 北向连续增持 + 低位 | 连续3日 + 低60日位 | 2 |

> **资金面满分 = 20分，触发信号需 ≥ 10分**

---

### 维度三：情绪面（权重 10%）

> 识别「散户情绪极端化 → 反向信号或确认信号」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **S1 股吧热度** | `bar_heat` | 近5日发帖量/30日均量 | > 3倍 | 3 |
| **S2 多空比** | `bull_bear_ratio` | 看多帖/看空帖 | 0.6-1.5区间（非极端） | 3 |
| **S3 新增关注** | `new_followers` | 周新增关注增速 | > 50% | 2 |
| **S4 雪球热度** | `xueqiu_heat` | 讨论量排名飙升 | 排名上升>100位 | 2 |

> **情绪面满分 = 10分，触发信号需 ≥ 5分**

---

### 维度四：消息面（权重 15%）

> 识别「政策催化 + 业绩超预期 + 重大事件」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **N1 业绩超预期** | `earnings_beat` | 净利润增速>50% 且 营收>20% | 同时满足 | 5 |
| **N2 政策催化** | `policy_catalyst` | 所属板块有国家级政策 | 近30天内 | 4 |
| **N3 重大合同** | `major_contract` | 公告大额订单/战略合作 | 单笔>营收20% | 3 |
| **N4 题材纯粹度** | `theme_purity` | 主营收入集中于1个核心赛道>70% | > 70% | 3 |

> **消息面满分 = 15分，触发信号需 ≥ 6分**

---

### 维度五：大盘行情（权重 10%）

> 识别「市场环境是否适合做多」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **M1 大盘趋势** | `market_trend` | 沪深300 > MA60 且 MA20 > MA60 | 满足 | 4 |
| **M2 市场量能** | `market_volume` | 两市成交额 | > 8000亿 | 3 |
| **M3 上涨家数** | `advance_ratio` | 上涨家数/总家数 | > 50% | 2 |
| **M4 涨停家数** | `limit_up_count` | 全市场涨停(不含ST) | > 50家 | 1 |

> **大盘面满分 = 10分，触发信号需 ≥ 5分**

---

### 维度六：机构参与度（权重 10%）

> 识别「机构是否在底部建仓」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **I1 基金持仓** | `fund_holding` | 基金持股/流通股 | 近2季持续增加 | 3 |
| **I2 分析师覆盖** | `analyst_coverage` | 近3月研报数量 | > 3篇且评级上调 | 2 |
| **I3 股东户数** | `shareholder_change` | 股东户数环比变化 | 减少 > 10% | 3 |
| **I4 融资余额** | `margin_balance` | 融资余额变化 | 连续增长 + 占流通市值<5% | 2 |

> **机构面满分 = 10分，触发信号需 ≥ 5分**

---

### 维度七：板块地位（权重 15%）

> 识别「是否为板块龙头、板块是否共振」

| 子指标 | 编码变量 | 计算方法 | 满分阈值 | 分值 |
|--------|------|------|------|:--:|
| **P1 板块RPS** | `sector_rps` | 所属板块近20日涨幅排名 | 前3名 | 4 |
| **P2 板块涨停梯队** | `sector_limit_up` | 同板块涨停家数 | > 3家（含龙头+跟风+补涨） | 4 |
| **P3 个股价位** | `price_rank_in_sector` | 近20日涨幅在板块内排名 | 前5名 | 3 |
| **P4 板块资金** | `sector_fund_flow` | 板块资金净流入 | > 50亿 | 2 |
| **P5 板块联动** | `sector_correlation` | 板块内个股涨跌相关性 | > 0.6 | 2 |

> **板块面满分 = 15分，触发信号需 ≥ 8分**

## 三、综合评分与信号触发

### 总分计算公式

```
总得分 = 技术面×0.20 + 资金面×0.20 + 情绪面×0.10 + 消息面×0.15 
       + 大盘面×0.10 + 机构面×0.10 + 板块面×0.15
```

### 信号等级

| 总分区间 | 信号等级 | 动作 | 仓位 |
|:--:|------|------|:--:|
| **≥ 70** | 🔥🔥🔥 强烈共振 | 重仓买入 | 正常仓位 × 1.5 |
| **60-69** | 🔥🔥 中等共振 | 标准买入 | 正常仓位 |
| **50-59** | 🔥 弱共振 | 轻仓试探 | 正常仓位 × 0.5 |
| **40-49** | 💤 观察区 | 加入观察列表，不买入 | 0 |
| **< 40** | ❌ 不满足 | 不操作 | 0 |

### 维度共振要求（必须满足）

```
即使总分达标，以下条件也必须满足，否则降一级：

1. 技术面 + 资金面 合计 ≥ 22分（这两个是牛股启动的必要条件）
2. 板块地位 ≥ 8分（孤军奋战的不碰）
3. 大盘行情 ≥ 5分（逆市不重仓）
```

## 四、退出机制

### 止盈规则

| 类型 | 条件 | 操作 |
|------|------|------|
| **移动止盈** | 从最高点回撤 > 15% | 卖出一半 |
| **趋势破坏** | 收盘价跌破 MA20 | 卖出剩余全部 |
| **量价背离** | 创新高但成交量萎缩 > 50% | 卖出三分之一 |
| **目标止盈** | 涨幅达 50% | 卖出三分之一 |
| **时间止盈** | 持仓 > 60个交易日 | 评估是否继续 |

### 止损规则

| 条件 | 操作 |
|------|------|
| 买入后跌幅 > 8% | 无条件止损 |
| 龙虎榜显示机构/游资大幅卖出 | 次日开盘卖出 |
| 基本面暴雷（业绩大变脸/ST） | 不计成本卖出 |
| 大盘进入单边下跌（沪深300跌破MA60） | 所有仓位减半 |
